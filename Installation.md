# Install the project

Python 3.13 skips the hidden editable path file currently generated by uv/Hatch for this project.
Install FastALPR as a regular wheel and use `--no-sync` so uv does not recreate the broken editable
installation:

```bash
uv sync --extra onnx --no-editable
```

# To generate test video

```bash
uv run --no-sync fast-alpr-video assets/videos/Cam-1.mp4 \
  --output-video assets/videos/Cam-1-annotated.mp4 \
  --output-csv assets/videos/Cam-1-detections.csv
```
